# 🪷 Loy Krathong 3D Online Festival (เทศกาลลอยกระทงออนไลน์)

เว็บแอปพลิเคชันเทศกาลลอยกระทงออนไลน์แบบ 3 มิติ พัฒนาด้วย **Vanilla HTML/CSS/JavaScript + Three.js** สัมผัสบรรยากาศคืนวันเพ็ญเดือนสิบสองริมแม่น้ำหน้าวัดไทยโบราณ ลอยกระทงร่วมกับผู้อื่นแบบเรียลไทม์ พร้อมโคมลอย ดอกไม้ไฟ ดนตรีไทยเดิม และผู้คนมาร่วมงานอย่างมีชีวิตชีวา

## ✨ ไฮไลต์และฟีเจอร์เด่น (Key Features)

- 🪷 **กระทง 3 มิติให้เลือก 2 รูปแบบ**:
  - **กระทงขนาดเล็ก**: กลีบใบตอง 8 กลีบ ดอกบัวหลวง และธูปเทียนแสงวอร์มไลท์
  - **กระทงขนาดกลาง**: กลีบใบตอง 2 ชั้นซ้อน 26 กลีบ ประดับดอกดาวเรือง ดอกบานไม่รู้โรย และธูปเทียน
- 🌊 **สายน้ำสาธารณะแบบเรียลไทม์ (Public River Sync)**:
  - เห็นกระทงของผู้ใช้อื่นลอยผ่านไปมาในแม่น้ำสายเดียวกันแบบ Real-time
  - **Privacy First**: เพื่อความเป็นส่วนตัว ระบบจะไม่แสดงคำอธิษฐานของผู้อื่นให้เห็น
- 🏛️ **ทัศนียภาพวัดไทยสีขาวทอง (White & Gold Temple Complex)**:
  - พระมหาเจดีย์ยอดฉัตรทองคำ 9 ชั้น และเจดีย์บริวารซ้าย-ขวา
  - ลานบันไดหินทอดยาวลงสู่แม่น้ำ พร้อมแสงส่องสว่างริมน้ำ
- 🏮 **บรรยากาศทไวไลท์ ยี่เป็ง และพลุไฟ (Twilight & FX)**:
  - ท้องฟ้าสีคราม (Blue Hour) พร้อมพระจันทร์เต็มดวงส่องประกายเงาสะท้อนลงบนผิวน้ำ
  - โคมลอยยี่เป็ง (Sky Lanterns) สีทองอร่ามลอยขึ้นสู่ท้องฟ้าอย่างนุ่มนวล
  - พลุดอกไม้ไฟ (Fireworks) จุดกระจายบนท้องฟ้าสลับสีสันสวยงาม
- 👥 **ผู้คนและท่าน้ำจำลอง (Crowd Simulation & Pier)**:
  - ตัวละครชุดไทยจำลอง (ชุดสไบ / ม่อฮ่อม) เดินมาร่วมงานที่สะพานท่าน้ำ
  - มีแอนิเมชันเดิน, นั่งคุกเข่า, พนมมือไหว้ (Wai), และปล่อยกระทงลงน้ำอย่างสมจริง
- 🚣 **เรือพายไทยและผางประทีปใบบัว (Boat & Lotus Lamps)**:
  - เรือพายไม้โบราณพร้อมคนพายเรือและหญิงสาวชุดไทยถือกระทง โคลงเคลงตามลูกคลื่น
  - กอใบบัวพร้อมถ้วยดินเผาจุดไฟ (ผางประทีป) ลอยเรืองรองอยู่ริมตลิ่ง
- 🎵 **ระบบเสียงอิสระ (Web Audio API)**:
  - **ดนตรีไทยเดิม**: เสียงขิมสังเคราะห์คอร์ดเบญจดุริยางค์ (Pentatonic Scale) ไพเราะจับใจ
  - **เสียงธรรมชาติ**: เสียงสายน้ำไหลเอื่อยและบรรยากาศริมน้ำ
  - สามารถเปิด-ปิดเสียงแต่ละประเภทแยกกันได้อย่างอิสระ
- 🎥 **มุมกล้อง 4 ทัศนียภาพ (Multi-Camera Modes)**:
  - ริมน้ำ (Dock View)
  - ท่าน้ำ (Pier View)
  - ตามกระทง (Follow Krathong View)
  - มุมกว้าง (Panoramic View)

## 🛠️ สถาปัตยกรรมและการพัฒนา (Architecture)

โปรเจกต์นี้ใช้ **Vanilla Three.js** ล้วน โดยสร้างโมเดล 3D แบบ **Procedural Generation** ผ่านรูปทรงเรขาคณิต (Primitives) ไม่ต้องดาวน์โหลดไฟล์โมเดลขนาดใหญ่ ทำให้โหลดหน้าเว็บได้รวดเร็วทันที

```
Loy-Krathong/
├── index.html                  # โครงสร้างหน้าเว็บ และ UI Controls
├── package.json                # ข้อมูลโปรเจกต์และการติดตั้ง Three.js
├── css/
│   └── style.css               # สไตล์ Glassmorphism และธีม Midnight Gold
├── js/
│   ├── main.js                 # Entry point และ Animation Loop รวม
│   ├── scene/
│   │   ├── SceneManager.js     # Three.js Scene, Camera, WebGL Renderer, Fog
│   │   ├── Lighting.js         # แสงแสงจันทร์ แสงแอมเบียนต์ แสงสปอตไลต์เจดีย์
│   │   ├── Water.js            # ผิวน้ำพร้อม Normal Map การกระเพื่อมของคลื่น
│   │   ├── Pagoda.js           # สถาปัตยกรรมพระเจดีย์และวัดไทย
│   │   └── Pier.js             # สะพานไม้ เสาไฟ และท่าเทียบเรือ
│   ├── entities/
│   │   ├── Krathong.js         # โมเดลกระทง 2 ขนาด พร้อมเปลวเทียน
│   │   ├── RiverFlow.js        # กระทงลอยน้ำ และการจัดการตำแหน่ง
│   │   ├── Character.js        # ตัวละครในชุดไทยพร้อมกระดูกท่าทาง
│   │   ├── CrowdManager.js     # ระบบจัดการการเดินและการลอยกระทงของผู้คน
│   │   ├── Boat.js             # เรือพายไทยพร้อมคนพาย
│   │   └── LotusPads.js        # ผางประทีปและกอใบบัว
│   ├── fx/
│   │   ├── SkyAndMoon.js       # ดวงจันทร์ ดวงดาว และโดมท้องฟ้า
│   │   ├── Lanterns.js         # โคมลอยยี่เป็งและแสงเรือง
│   │   └── Fireworks.js        # พลุดอกไม้ไฟอนุภาคฟิสิกส์
│   ├── audio/
│   │   └── SoundManager.js     # สังเคราะห์เสียงดนตรีไทยและน้ำไหล (Web Audio)
│   └── network/
│       └── SyncManager.js      # ระบบเชื่อมต่อกระทงสาธารณะ (BroadcastChannel)
└── LOY_KRATHONG_PLAN.md        # แผนงานและการพัฒนา
```

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

### ความต้องการของระบบ (Prerequisites)
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป) หรือ Python 3

### 1. โคลน Repository
```bash
git clone https://github.com/6927tech/Loy-Krathong.git
cd Loy-Krathong
```

### 2. ติดตั้ง Dependencies
```bash
npm install
```

### 3. เริ่มต้น Web Server

สามารถใช้คำสั่งใดคำสั่งหนึ่งด้านล่างนี้:

**ตัวเลือก A: ใช้ Python (แนะนำ สะดวกและรวดเร็ว)**
```bash
python3 -m http.server 3000
```

**ตัวเลือก B: ใช้ Node.js npx serve**
```bash
npx serve -l 3000
```

### 4. เปิดเบราว์เซอร์
เข้าใช้งานผ่านเบราว์เซอร์ได้ที่:
```
http://localhost:3000
```

## 🎮 การใช้งาน (How to Play)

1. คลิกที่หน้าจอ 1 ครั้งเพื่อเปิดระบบเสียง (Audio)
2. เลือก **ขนาดกระทง** ที่ต้องการ (ขนาดกะทัดรัด หรือ ขนาดกลาง)
3. พิมพ์ **ชื่อของคุณ** และ **คำอธิษฐาน** (หรือคลิกแท็กคำอวยพรสำเร็จรูป)
4. กดปุ่ม **"ลอยกระทง"** เพื่อปล่อยกระทงลงสู่แม่น้ำ
5. สลับเปลี่ยนมุมกล้องด้านขวาบนเพื่อชมกระทงของคุณลอยคู่ไปกับกระทงท่านอื่นในสายน้ำ

## ⚡ การปรับแต่งประสิทธิภาพ (Performance)

- ล็อกเฟรมเรตคงที่ 60 FPS ด้วยการควบคุมจำนวน Dynamic PointLight
- ใช้วัสดุ `MeshStandardMaterial` ร่วมกับ Normal Map สำหรับผิวน้ำ แทนการเรนเดอร์กระจกเงาสองรอบ (Planar Reflection)
- ตัวละครและโคมลอยใช้เทคนิค Low-poly Optimized Geometry
